# Iris Flower Classifier 🌸
My first machine learning project. Built this while exploring ML for the first time.

## What it does
Takes 4 measurements of an iris flower (sepal length, sepal width, 
petal length, petal width) and predicts which of 3 species it belongs to —
Setosa, Versicolor, or Virginica.

## Algorithm used
K-Nearest Neighbors (KNN) with n_neighbors=3

## Results
- Accuracy: 96.67%
- F1 Score: 0.97
- Dataset: Iris Dataset (150 samples, built into scikit-learn)

## What I learned
- How the ML workflow actually works (load → explore → train → evaluate)
- Why train/test split matters
- How KNN makes decisions
- That petal measurements separate species better than sepal measurements

## Libraries used
- Python
- scikit-learn
- pandas
- matplotlib

## How to run
Open the `.ipynb` file in Google Colab and run all cells top to bottom.
